# Smart Bin

Nachrüstung für Recyclingstationen (PET | ALU | REST): Bilderkennung pro Einwurf,
LED-Rückmeldung bei Fehlwürfen und eine Klappe, die den Gegenstand in den richtigen
Behälter lenkt.

**3D-Simulation im Browser:** <https://cuenotfl.github.io/smartbin-sim/>
(ohne Installation; die echte Software läuft direkt im Browser)
